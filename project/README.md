# AI 기반 LAN 공격 탐지 및 자동 대응 시스템

컴퓨터네트워크 2026-2 팀 프로젝트 (9~15주차)

## 해결하려는 문제

ARP와 DHCP는 인증 절차가 없습니다. 그래서 같은 LAN 안의 공격자가 ARP 스푸핑이나 가짜 DHCP 서버만으로 중간자 공격(MITM)을 할 수 있습니다. 일반 사용자는 이런 공격을 알아채기 어렵습니다.

## 접근 방법

1. 격리된 가상 LAN(VM, Mininet)에서 공격을 재현합니다.
2. Scapy로 패킷을 실시간 캡처하고 ARP, DHCP, 플로우 특징을 추출합니다.
3. **규칙 기반 탐지기**와 **AI 모델**(공개 데이터셋 Kitsune Network Attack으로 학습하고, 실험망 데이터로 추가 학습)로 공격을 판정합니다.
4. 공격이 탐지되면 대시보드와 디스코드로 경보를 보내고, **SDN 컨트롤러(Ryu)가 공격자 포트를 자동으로 차단**합니다.
5. 규칙, AI, 혼합 방식의 탐지율, 오탐률, 탐지 시간을 비교합니다.

## 탐지 대상 공격

| 공격 | 계층 | 관련 실습 |
|---|---|---|
| ARP 스푸핑 / 중간자 공격 | L2 | w07 |
| MAC 플러딩 (CAM 테이블 고갈) | L2 | w07 |
| 가짜 DHCP 서버 / DHCP 고갈 | L3 | w05 |
| 네트워크·포트 스캔 | L3/L4 | w04 |
| SYN flood | L4 | w04 |
| DNS 스푸핑 (확장 목표) | L7 | w03 |

## 시스템 구조

```
[env] 공격·정상 트래픽 발생
        │
        ▼
[capture] 실시간 캡처 → 특징 추출 ──┬──▶ [model] AI 판정 ──┐
                                    └──▶ [rules] 규칙 판정 ─┤
                                                           ▼
                                  [dashboard] 경보·근거 표시, 디스코드 알림
                                  [sdn] 공격자 포트 자동 차단
```

## 추가 기능

다른 팀과 구분되는 점을 보여 주려고 넣는 기능입니다. 아래 일정표에서 ★로 표시합니다.

| 우선순위 | 기능 | 내용 | 담당 |
|---|---|---|---|
| 필수 | ★ 사전 차단 | Ryu가 DHCP 응답으로 IP-MAC-포트 대응표를 만들고, 표와 맞지 않는 ARP를 미리 버림 (DHCP Snooping, DAI 방식) | 송정훈 |
| 필수 | ★ 회피 공격 실험 | 탐지를 피하려는 공격(느린 ARP 스푸핑, 느린 포트 스캔, 저속 SYN flood, 정상 트래픽에 섞은 공격)을 규칙과 AI가 각각 잡는지 비교 | 조현성, 최대환 |
| 필수 | ★ 대응 시간 측정 | 공격 시작 → 탐지 → 차단 완료까지 걸린 시간 측정 | 박상언 |
| 선택 | ☆ 경보 패킷 저장 | 경보 앞뒤 몇 초의 패킷을 pcap으로 저장하고 대시보드에서 내려받기 | 김욱 |
| 선택 | ☆ 차단 해제 | 차단 시간 제한, 대시보드에서 관리자가 차단 해제 | 송정훈, 박상언 |

## 기술 스택

Python 3, Scapy, Mininet, Ryu(또는 OS-Ken), scikit-learn, SHAP, Streamlit, Wireshark, Ubuntu VM

## 안전 수칙

- 모든 공격 실험은 **격리된 가상 환경(VM, Mininet) 안에서만** 수행합니다.
- 학교망, 공용 와이파이, 타인의 네트워크에서는 절대 실행하지 않습니다.
- 캡처 파일을 올리기 전에 실제 MAC, IP 등 개인 식별 정보를 제거합니다.
